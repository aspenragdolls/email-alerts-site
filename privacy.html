Privacy Policy

email-summary-alerts · Last updated September 28, 2026

email-summary-alerts ("the app") is a personal tool built and used by a single person, its developer. It is not offered to the public. This policy explains what the app does with Google user data.

Data the app accesses

With the account owner's permission, the app uses the Gmail API with the read-only scope (https://www.googleapis.com/auth/gmail.readonly) to read new messages in the owner's inbox: sender, subject, date, and message text. The app cannot send, delete, or change email.

How the data is used

Each new email is analyzed by an AI model running locally on the owner's own computer to estimate its urgency and importance and to write a one-sentence summary. Summaries of important emails are sent to the owner's own phone through a private Telegram bot that only responds to the owner.

Storage

The app stores email metadata (sender, subject, a short snippet), the generated scores and summaries, and the owner's own prioritization rules in a database file on the owner's computer. The Gmail authorization token is stored on the same computer. Nothing is stored on any server operated by the app.

Sharing

Google user data is not sold, shared with, or transferred to anyone. It is not used for advertising, and it is not used to train AI models. The only transmission outside the owner's computer is the owner's own summaries delivered to the owner through Telegram.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete the local database file to remove all stored data.
